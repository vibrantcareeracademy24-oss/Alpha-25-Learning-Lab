# Alpha 25 Learning Lab

Single-repository educational website framework for Balvatika to Standard 8.

## Structure
- `index.html` — Home
- `pages/` — all website modules
- `data/` — reusable learning data
- `assets/images/` — add images here
- `assets/audio/` — add MP3 audio here
- `style.css` — common design
- `app.js` — common navigation, speech and answer helpers

## GitHub Pages
1. Create a repository named `alpha-25-learning-lab`.
2. Upload all files/folders from this ZIP.
3. Repository Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

## Important
This ZIP is a working starter framework with demo content. The full requested question bank (all textbook chapters), 2200 GK questions, 90 stories, complete Spoken English/Phonics content, images and MP3 files can be populated in the `data/` and `assets/` folders without changing the overall site structure.
